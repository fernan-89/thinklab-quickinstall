# Changelog

## [1.0.0] - unreleased

First public version.

* Data-driven kit: `catalog.json`, `software.json`, `site.json` (private) -> `New-Kit.ps1` builds answer files, Ventoy menu, theme, PE tools and bilingual docs.
* Windows 10/11/LTSC/IoT/Server 2019 answer files (EN-US, PT-BR) with a manual disk step, generic install keys, computer names <= 15 characters.
* `FirstLogon.ps1`: profile driven post-install (drivers, Office offline, software), `inventory.json`, forced password change.
* **BASE** templates for every Windows ISO and for AlmaLinux / Ubuntu Server.
* Linux: AlmaLinux 10 kickstarts (Workstation + Server), Ubuntu Server autoinstall, openSUSE Leap (interactive).
* Recovery menu: Hiren's BootCD PE (+ injected ThinkLab tools), SystemRescue, GParted Live, Clonezilla Live, MemTest86+; checksums verified on download.
* ThinkLab Ventoy theme (TreeView, class icons) and an offline bilingual documentation site.
* `New-Manifest.ps1` / `Verify-Stick.ps1`; `tests/Test-Repo.ps1` with syntax, example build and privacy checks; pre-commit hook.
* Hyper-V test tooling: virtual test stick, VM helpers, WMI screenshots and keyboard, read-only guest log extraction.
* OEM branding (System Properties: manufacturer, model + computer name, logo, optional support info) and per-machine wallpaper sets (own artwork generated by `Build-Branding.ps1`; vendor wallpapers are supplied locally, never committed).
* Per-kit `extraSoftware` in `site.json` (for example security suite, password manager, VPN installers placed in `Software\` per language).
* Winget/installer watchdog: installers that finish but keep a window open no longer block the post-install.
* Netdata monitoring on every server kit: Windows Server (local signed MSI from `Software\`) and Linux servers (AlmaLinux/Ubuntu: one-shot first-boot unit that runs the official kickstart once the network is up).
* Software filters fall back to a `_Multi` installer and pick the newest version when several match (language-specific installers such as Kaspersky).
* Red Hat Enterprise Linux 10 and CentOS Stream 10 kits (workstation EN/PT, server EN) next to AlmaLinux; CentOS installs from the boot ISO over the network.
* Windows Server kits for both Standard and Datacenter (Desktop Experience), per machine and BASE. Servers are English only.

### Fixed during validation

* Ventoy menu showed only Linux entries: `VTOY_MENU_TIMEOUT=0` made Ventoy boot the first image immediately.
* Windows Server keeps the stick disk offline: a first command brings disks online and mounts the Ventoy volume before the first-logon scan.
* Windows Server: `AdministratorPassword` must be inside `UserAccounts`; the Ventoy volume gets a drive letter before the first-logon scan (Server does not auto-mount volumes).
* FirstLogonCommands 259-character limit: the answer file now carries a tiny bootstrap; parameters live in `Scripts\kits.json`.
* Template order is stable (BASE first, then machines in site order).
* First-logon bootstrap now waits for the `Ventoy` volume (it was a race on Windows 10) and logs when it cannot find it.
