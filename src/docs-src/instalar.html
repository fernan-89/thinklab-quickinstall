Passo a passo

Da máquina desligada ao sistema pronto.

  1. Plugue o pen-drive e ligue a máquina. Use a tecla do menu de boot da máquina (em muitos Lenovo, F12) para abrir o menu de boot e escolha o pen-drive (UEFI ou Legacy; o menu é o mesmo).
  2. No menu do Ventoy, entre em Windows e escolha a ISO (por exemplo "Windows 11 26H2 - PORTUGUES"). Na pergunta de modo, escolha Boot in normal mode.
  3. Escolha o modelo da sua máquina na lista (/Unattend/<MÁQUINA>_..., ou BASE_... para qualquer máquina). Para instalação limpa, escolha Boot without auto installation template.
  4. Escolha o disco. O instalador já definiu idioma, teclado, edição e chave genérica; só pergunta onde instalar. Escolha o disco da máquina e nunca as partições Ventoy ou VTOYEFI.
  5. Aguarde. Depois do primeiro logon (usuário {{ADMIN_USER}}) o script FirstLogon.ps1 roda sozinho: instala drivers, Office e programas. Deixe o pen-drive plugado até o fim.
  6. Reinicie quando a janela terminar (Docker, WSL e drivers pedem reinício) e troque a senha padrão.
Onde ficam os registrosC:\QuickInstall guarda o log do script e as configurações do Office que foram usadas.
Secure BootNa primeira vez em cada máquina, com Secure Boot ligado, o Ventoy mostra uma tela azul "Enroll MOK": escolha Enroll key from disk e o arquivo ENROLL_THIS_KEY_IN_MOKMANAGER.cer. Sem isso o boot é recusado.

Step by step

From a powered-off machine to a finished system.

  1. Plug the stick and power on. Press the machine's boot-menu key (on many Lenovo, F12) for the boot menu and pick the stick (UEFI or Legacy; the menu is the same).
  2. In the Ventoy menu open Windows and pick the ISO (for example "Windows 11 26H2 - ENGLISH"). At the mode question choose Boot in normal mode.
  3. Pick your machine's template from the list (/Unattend/<MACHINE>_..., or BASE_... for any machine). For a clean install pick Boot without auto installation template.
  4. Choose the disk. Setup already knows language, keyboard, edition and the generic key; it only asks where to install. Choose the machine's disk and never the Ventoy or VTOYEFI partitions.
  5. Wait. After the first logon (user {{ADMIN_USER}}) the FirstLogon.ps1 script runs by itself: drivers, Office and programs. Keep the stick plugged in until it ends.
  6. Reboot when the window finishes (Docker, WSL and drivers need it) and change the default password.
Where the logs areC:\QuickInstall holds the script log and the Office configurations that were used.
Secure BootThe first time on each machine, with Secure Boot on, Ventoy shows a blue "Enroll MOK" screen: choose Enroll key from disk and the file ENROLL_THIS_KEY_IN_MOKMANAGER.cer. Without it the boot is refused.
