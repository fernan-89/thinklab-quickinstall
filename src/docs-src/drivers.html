Se o disco não aparecer no instaladorEm máquinas com Intel VMD/RST o Windows Setup pode não ver o NVMe. Use "Carregar driver" e aponte para a pasta de drivers de armazenamento do fabricante, ou mude o modo de armazenamento na BIOS.

Drivers

Packs live in Drivers\ on the stick and are installed with pnputil at the first logon. Windows Update fills in whatever is missing.

{{DRIVERS_TABLE}}
If the disk does not show up in SetupOn machines with Intel VMD/RST, Windows Setup may not see the NVMe. Use "Load driver" and point to the vendor's storage driver folder, or change the storage mode in the BIOS.
To export what is already installedOn the real machine: pnputil /export-driver * C:\Drivers (as administrator) produces an exact pack of the current drivers.
