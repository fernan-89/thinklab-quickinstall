Arquivos do pen-drive

Tudo o que existe nas pastas ISO, Office, Software e Drivers. Os nomes seguem o padrão Produto_Detalhe_Arq_Versão_Idioma.ext, com versão e idioma no fim.

Lendo os nomesMulti = instalador multilíngue; Any = instalador sem arquitetura fixa; x64/x86 = arquitetura. Em ISOs, a versão traz também a build (por exemplo 22H2-19045.6456).

Files on the stick

Everything in the ISO, Office, Software and Drivers folders. Names follow the pattern Product_Detail_Arch_Version_Language.ext, with version and language at the end.

Reading the namesMulti = multilingual installer; Any = installer with no fixed architecture; x64/x86 = architecture. On ISOs the version also carries the build (for example 22H2-19045.6456).
