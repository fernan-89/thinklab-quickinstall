What the kit delivers

  • Ready-to-use Windows: system, drivers, Office (ProPlus, Visio, Project Pro and, for 2021, Publisher) and the programs of each profile, with language and keyboard already set.
  • Clean install: every ISO also offers "Boot without auto installation template".
  • Linux: Ubuntu Server, AlmaLinux (Red Hat family) and openSUSE Leap, all free.
  • Recovery: Hiren's BootCD PE (Windows Live) and four Linux rescue tools.
Mind the diskDisk selection is always manual, on purpose. On the "Where do you want to install Windows?" screen the stick's own partitions (Ventoy and VTOYEFI) also show up: never pick those.
