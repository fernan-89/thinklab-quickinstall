Windows Live e resgate

Um conjunto de ambientes que rodam direto do pen-drive, sem instalar nada: um Windows Live (WinPE) no estilo Hiren's BootCD e quatro ferramentas Linux de resgate. Todas são livres e estão na pasta Recovery do menu.

FerramentaVersãoPara que serve
Hiren's BootCD PEx64, 2024-03Windows 11 PE com área de trabalho e dezenas de programas portáteis: discos e partições, backup e clonagem, recuperação de arquivos, redefinição de senha, antivírus, rede e diagnóstico de hardware.
SystemRescue13.03Linux de resgate: reparo de sistemas de arquivos, NTFS/ext4/btrfs, cópia e recuperação de dados, rede, SSH e ferramentas de disco em modo texto ou gráfico.
GParted Live1.8.1-3Particionamento gráfico: redimensionar, mover, copiar e reparar partições.
Clonezilla Live3.3.3-37Imagem e clonagem de discos e partições, local ou pela rede (equivalente a um Ghost livre).
MemTest86+9.00Teste de memória RAM, inicia direto, sem sistema operacional.

Quando usar cada uma

  • O Windows não inicia: Hiren's BootCD PE (reparo de boot, redefinir senha, copiar arquivos para um disco externo).
  • Disco com defeito ou cheio: GParted Live ou SystemRescue para ver e consertar partições; Clonezilla para fazer uma imagem antes de mexer.
  • Travamentos e telas azuis: MemTest86+ para descartar a memória.
  • Máquina sem sistema: volte ao menu de instalação do kit.

Ferramentas ThinkLab dentro do Hiren's PE

O menu injeta um pacote próprio (ventoy\inject\ThinkLab-PE-Extras.zip) no Windows Live. Quatro atalhos aparecem na área de trabalho:

  • ThinkLab Docs: abre esta documentação do pen-drive.
  • Load stick drivers: carrega no Windows Live os drivers de uma máquina da pasta Drivers\ (rede, armazenamento).
  • Export Windows drivers: exporta os drivers de um Windows instalado (offline) para Drivers\_Exported no pen-drive, antes de reinstalar.
  • Collect install logs: copia o C:\QuickInstall de um Windows instalado para Logs\ no pen-drive.
Drivers dentro do Windows LiveOs drivers do kit continuam na pasta Drivers\ do pen-drive. Dentro do Hiren's PE o pen-drive aparece como uma unidade com o rótulo Ventoy; se faltar rede ou disco, use drvload com o .inf do pacote da máquina.
CuidadoFerramentas de recuperação alteram discos. Faça imagem ou cópia do que importa antes de reparar, redimensionar ou limpar.

Windows Live and rescue

A set of environments that run straight from the stick, installing nothing: a Windows Live (WinPE) in the style of Hiren's BootCD and four Linux rescue tools. All are free and sit in the Recovery folder of the menu.

ToolVersionWhat it is for
Hiren's BootCD PEx64, 2024-03Windows 11 PE with a desktop and dozens of portable programs: disks and partitions, backup and cloning, file recovery, password reset, antivirus, network and hardware diagnostics.
SystemRescue13.03Rescue Linux: filesystem repair, NTFS/ext4/btrfs, data copy and recovery, network, SSH and disk tools in text or graphical mode.
GParted Live1.8.1-3Graphical partitioning: resize, move, copy and repair partitions.
Clonezilla Live3.3.3-37Disk and partition imaging and cloning, local or over the network (a free Ghost equivalent).
MemTest86+9.00RAM test, starts directly with no operating system.

When to use each one

  • Windows will not start: Hiren's BootCD PE (boot repair, password reset, copy files to an external disk).
  • Faulty or full disk: GParted Live or SystemRescue to inspect and fix partitions; Clonezilla to image the disk before touching it.
  • Freezes and blue screens: MemTest86+ to rule out the memory.
  • Machine with no system: go back to the kit's install menu.

ThinkLab tools inside Hiren's PE

The menu injects its own package (ventoy\inject\ThinkLab-PE-Extras.zip) into the Windows Live. Four shortcuts show up on the desktop:

  • ThinkLab Docs: opens this documentation from the stick.
  • Load stick drivers: loads the drivers of a machine from the Drivers\ folder into the Windows Live (network, storage).
  • Export Windows drivers: exports the drivers of an installed (offline) Windows to Drivers\_Exported on the stick, before reinstalling.
  • Collect install logs: copies C:\QuickInstall of an installed Windows to Logs\ on the stick.
Drivers inside the Windows LiveThe kit's drivers stay in the stick's Drivers\ folder. Inside Hiren's PE the stick shows up as a drive labelled Ventoy; if network or disk is missing, use drvload with the .inf of the machine's pack.
CarefulRecovery tools change disks. Image or copy what matters before repairing, resizing or wiping.
