Software and Office

What each profile installs by itself after the first logon. Installers live in Software\ on the stick; anything missing there comes from winget (needs internet).

Office

SystemOfficeProducts
Windows 10, IoT, LTSC 20212021ProPlus, Visio Pro, Project Pro, Publisher
Windows 11, LTSC 20242024ProPlus, Visio Pro, Project Pro (Publisher does not exist in 2024)
  • Portuguese kits install Office in pt-BR only; English kits, en-US only.
  • The source is the bilingual folder Office\pt-BR\Office-Retail-CurrentChannel_..., installed by the Office Deployment Tool (Office\_ODT\setup.exe, signed by Microsoft).
  • The editions are Retail: they activate with your key or Microsoft account.

Programs per profile

BASE optionThe BASE_... templates install only Windows and its matching Office: no drivers (Windows Update handles those) and none of the programs above.
NotesAdobe Reader uses winget with the pt-BR locale on Portuguese kits; on English kits it uses the web downloader, which also needs internet. Epic Games may open its own wizard. Importing the Xencelabs profiles is manual (Documents\Xencelabs-Profiles). 7-Zip is not used in any profile.
