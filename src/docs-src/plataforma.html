Integração ThinkLab

O Quick Install é o add-on de provisionamento da plataforma ThinkLab: cada máquina nasce já identificada, padronizada e com os dados prontos para entrar no seu inventário.

{{DIAGRAM:platform}}

O que cada instalação deixa pronto

  • Ativos e descoberta: o inventory.json (nome, modelo, sistema, idioma, perfil, data) descreve o equipamento; é a entrada natural do registro de ativos e da descoberta.
  • Licenças: Office e segurança (Kaspersky) instalados por kit, com o idioma do sistema; a ativação fica com a sua conta.
  • Patches e manutenção de hardware: a pasta de drivers e o pacote Lenovo usados em cada máquina ficam registrados no log do primeiro logon.
  • Saúde: servidores Windows e Linux sobem com o Netdata, pronto para o monitoramento.
  • Identidade: o nome do computador, o fabricante "ThinkLab" nas Propriedades do Sistema e o papel de parede seguem o padrão do site.json.
EscopoEste kit gera e deixa os dados no C:\QuickInstall de cada máquina. A importação automática para os módulos do ThinkLab é uma funcionalidade do lado da plataforma e não faz parte deste repositório.

ThinkLab integration

Quick Install is the provisioning add-on of the ThinkLab platform: every machine is born identified, standardised and with data ready to enter your inventory.

{{DIAGRAM:platform}}

What every install leaves ready

  • Assets and discovery: inventory.json (name, model, system, language, profile, date) describes the device; it is the natural input for the asset registry and for discovery.
  • Licences: Office and security (Kaspersky) installed per kit in the system language; activation stays with your account.
  • Patches and hardware maintenance: the driver folder and the Lenovo pack used on each machine are recorded in the first-logon log.
  • Health: Windows and Linux servers come up with Netdata, ready for monitoring.
  • Identity: computer name, the "ThinkLab" manufacturer in System Properties and the wallpaper follow the site.json standard.
ScopeThis kit produces the data and leaves it in C:\QuickInstall on each machine. Automatic import into the ThinkLab modules is a platform-side feature and is not part of this repository.
