Clusters: por máquina ou por sistema

Leia a matriz em duas direções: cada linha é uma máquina (todos os kits dela) e cada coluna é um sistema (todas as máquinas que o recebem). A altura do cubo é a quantidade de kits (idiomas, edições e versões); a cor indica a família. No menu de boot o mesmo agrupamento aparece assim: a árvore agrupa por sistema e, dentro de cada ISO, os kits ficam agrupados por máquina.

Como ler o nome

  • W10/W11 Windows 10/11, S19 Server 2019, I10 Windows 10 IoT, L21/L24 LTSC 2021/2024; no Linux, a10 = AlmaLinux 10 e u26 = Ubuntu 26.
  • Idioma: E inglês, P português. Papel: F completo, D desenvolvimento, O escritório, S servidor.
Limite de 15 caracteresOs nomes de computador Windows seguem o limite NetBIOS de 15 caracteres.

Reading the name
