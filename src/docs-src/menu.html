Teclas úteis

  • F1 ajuda, F2 navegar em arquivos, F3 alternar lista/árvore, F4 boot do disco local, F5 ferramentas, F6 menu estendido.
  • Em ISOs do Windows, Boot in wimboot mode é uma alternativa se o modo normal falhar.

Como funcionam os modelos

Cada ISO de instalação mostra uma lista de modelos (/Unattend/...). O modelo define idioma, teclado, edição, nome do computador e o perfil de programas. A primeira opção da lista, Boot without auto installation template, abre o instalador normal, sem automação.

Opção Base

Além dos modelos por máquina, cada ISO de instalação tem um modelo BASE_...: instala somente aquela versão do Windows e o Office correspondente (2021 no Windows 10, IoT e LTSC 2021; 2024 no Windows 11 e LTSC 2024), sem drivers, sem programas adicionais e sem nome de computador fixo (o Windows escolhe um). No Windows Server 2019 a base é só o sistema.

No Linux, os modelos BASE_... servem a qualquer máquina: AlmaLinux Workstation e Server em inglês e português, e Ubuntu Server em inglês. O openSUSE já é genérico por natureza.

Useful keys

  • F1 help, F2 browse files, F3 switch list/tree, F4 boot the local disk, F5 tools, F6 extended menu.
  • On Windows ISOs, Boot in wimboot mode is an alternative if normal mode fails.

How the templates work

Each install ISO shows a list of templates (/Unattend/...). The template sets language, keyboard, edition, computer name and the software profile. The first entry, Boot without auto installation template, opens the regular installer with no automation.

Base option

Besides the per-machine templates, every install ISO has a BASE_... template: it installs only that Windows version and its matching Office (2021 on Windows 10, IoT and LTSC 2021; 2024 on Windows 11 and LTSC 2024), with no drivers, no extra programs and no fixed computer name (Windows picks one). On Windows Server 2019 the base is the system alone.

On Linux, the BASE_... templates fit any machine: AlmaLinux Workstation and Server in English and Portuguese, and Ubuntu Server in English. openSUSE is generic by nature.
