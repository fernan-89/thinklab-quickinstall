Solução de problemas

O menu não aparece ou volta direto para o sistema

  • Abra o menu de boot da máquina (em muitos Lenovo, F12) e escolha o pen-drive pelo nome; no UEFI procure a entrada "UEFI: ... USB".
  • Com Secure Boot ligado, aceite a chave do Ventoy na tela azul "Enroll MOK" (Passo a passo) ou desligue o Secure Boot.

Só aparece uma pasta ou poucas ISOs

  • O menu usa a visão em árvore: entre nas pastas Windows, Linux e Recovery. F3 alterna para a lista completa.
  • O arquivo ventoy\ventoy.json não pode ter VTOY_MENU_TIMEOUT igual a 0: isso faz o Ventoy iniciar a primeira ISO sozinho (foi a causa do problema "só Linux").

Clonezilla ou GParted Live param em "Waiting for single CPU status"

  • Aparece em máquinas virtuais Hyper-V com mais de um processador. Em máquina real isso não ocorre; numa VM use 1 vCPU para essas duas ferramentas.

O instalador do Windows não acha o disco

  • Máquinas com Intel VMD/RST: carregue o driver de armazenamento ("Carregar driver") ou mude o modo na BIOS.

O Windows 11 recusa a instalação

  • Ligue o TPM 2.0 (fTPM em máquinas AMD) e o Secure Boot na BIOS.
  • CPUs fora da lista oficial do Windows 11 podem recusar a instalação; verifique antes.

O pós-instalação não rodou ou parou

  • Veja o log em C:\QuickInstall. O script segue para o próximo item quando um falha.
  • Mantenha o pen-drive plugado: o script procura o volume Ventoy.
  • Reader e Firefox Developer dependem de internet quando o instalador local não está no kit; o winget pode não existir no Windows 10 recém-instalado.

Office em inglês nos kits em português

  • Confirme que a pasta Office\pt-BR\Office-Retail-CurrentChannel_... e o arquivo Office\_ODT\setup.exe estão no pen-drive.

Troubleshooting

The menu does not show up or goes straight to the system

  • Open the machine's boot menu (on many Lenovo, F12) and pick the stick by name; on UEFI look for the "UEFI: ... USB" entry.
  • With Secure Boot on, accept the Ventoy key on the blue "Enroll MOK" screen (Step by step) or turn Secure Boot off.

Only one folder or a few ISOs show

  • The menu uses the tree view: open the Windows, Linux and Recovery folders. F3 switches to the full list.
  • ventoy\ventoy.json must not have VTOY_MENU_TIMEOUT set to 0: that makes Ventoy start the first ISO by itself (this was the cause of the "Linux only" problem).

Clonezilla or GParted Live stop at "Waiting for single CPU status"

  • This shows up in Hyper-V virtual machines with more than one processor. It does not happen on real hardware; in a VM use 1 vCPU for these two tools.

Windows Setup cannot find the disk

  • Machines with Intel VMD/RST: load the storage driver ("Load driver") or change the mode in the BIOS.

Windows 11 refuses to install

  • Turn on TPM 2.0 (fTPM on AMD machines) and Secure Boot in the BIOS.
  • CPUs outside the official Windows 11 list may refuse to install; check beforehand.

Post-install did not run or stopped

  • Read the log in C:\QuickInstall. The script moves on to the next item when one fails.
  • Keep the stick plugged in: the script looks for the Ventoy volume.
  • Reader and Firefox Developer need internet when the local installer is not in the kit; winget may not exist on a fresh Windows 10.

Office is in English on the Portuguese kits

  • Check that the folder Office\pt-BR\Office-Retail-CurrentChannel_... and the file Office\_ODT\setup.exe are on the stick.
