Manutenção

Como atualizar ou refazer o pen-drive. As ferramentas ficam na máquina de montagem, no repositório.

Estrutura do pen-drive

PastaConteúdo
ISO\Imagens do menu, em pastas por grupo (Windows, Linux, Recovery).
Office\Ferramenta de implantação e a origem bilíngue do Office.
Software\Instaladores dos programas.
Drivers\Pacotes de drivers por máquina.
Unattend\Arquivos de resposta: XML (Windows), kickstart (AlmaLinux) e YAML (Ubuntu).
Scripts\FirstLogon.ps1, o pós-instalação do Windows.
ventoy\ventoy.json (menu, apelidos, modelos) e o tema ThinkLab.
Docs\Esta documentação.

Rotinas

  • Montar tudo (modelos, menu, tema, documentação, scripts): src\tools\New-Kit.ps1.
  • Publicar no pen-drive: src\tools\Publish-Stick.ps1 (confere se o volume se chama Ventoy).
  • Baixar ISOs de resgate: src\tools\Get-RescueIsos.ps1 (confere os checksums publicados).
  • Conferir o pen-drive: Scripts\Verify-Stick.ps1 compara tudo com o SHA256SUMS.txt.
  • Testar sem máquina real: src\tools\Test-StickImageInHyperV.ps1 copia o pen-drive para um disco virtual e sobe uma VM.
Regra do menuNunca use VTOY_MENU_TIMEOUT = 0 no ventoy.json. Alterar nomes de ISO exige ajustar o ventoy.json.

Maintenance

How to update or rebuild the stick. The tools live on the build machine, in the repository.

Stick layout

FolderContents
ISO\Menu images, in group folders (Windows, Linux, Recovery).
Office\Deployment tool and the bilingual Office source.
Software\Program installers.
Drivers\Driver packs per machine.
Unattend\Answer files: XML (Windows), kickstart (AlmaLinux) and YAML (Ubuntu).
Scripts\FirstLogon.ps1, the Windows post-install.
ventoy\ventoy.json (menu, aliases, templates) and the ThinkLab theme.
Docs\This documentation.

Routines

  • Build everything (templates, menu, theme, docs, scripts): src\tools\New-Kit.ps1.
  • Publish to the stick: src\tools\Publish-Stick.ps1 (checks the volume is called Ventoy).
  • Download rescue ISOs: src\tools\Get-RescueIsos.ps1 (checks the published checksums).
  • Verify the stick: Scripts\Verify-Stick.ps1 compares everything with SHA256SUMS.txt.
  • Test without a real machine: src\tools\Test-StickImageInHyperV.ps1 copies the stick to a virtual disk and starts a VM.
Menu ruleNever use VTOY_MENU_TIMEOUT = 0 in ventoy.json. Renaming ISOs requires updating ventoy.json.
